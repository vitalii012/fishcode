***FishCode*** or ***fishcode*** is an easy-to-use, cross-platform command-line tool.

***FishCode*** can be used to cryptographically protect sensitive data that needs to be safeguarded
against unauthorized access. Basically, you can use FishCode to encrypt particularly valuable files
on your computer. Key features of this program include the use of the attack-resistant AES-GCM algorithm
and multi-threaded file processing, which ensures high security and performance.

***FishCode*** is currently in the early stages of development, so the application's functionality is
constantly evolving, which may cause incompatibility between different versions. I am working on this
project on my own, in my free time, so please do not expect frequent updates.
